# METAL SHIFTER

Godot 4.x で制作する、斜め視点の2D横スクロール・メカアクションゲーム。

## 起動方法
1. Godot 4.2以降でこのフォルダの `project.godot` をインポート
2. F6ではなく F5 でメインシーンを実行

## 操作
- A / D または左右矢印: 移動
- Space: ジャンプ

## 現在の実装
- 地面、背景、カメラ追従
- 加減速付き左右移動、ジャンプ、衝突判定
- 待機時の上下動と歩行時の脚部アニメーション
- 頭部・胴体・脚部・肩武器・腕武器を個別ノードで管理

## 今後の予定
- 生成済みGIFをパーツ別の透過PNGへ整理して差し替え
- 装備データ（Resource）によるパーツ換装
- 射撃、敵、アイテムドロップ、ハンガー画面

**注意**: 初期版はプログラムで描画した仮メカです。生成済みGIFの画像自体はまだリポジトリへ組み込んでいません。

## アニメーション画像の導入
1. ChatGPTから `metal-shifter-motion-assets.zip` をダウンロード
2. 展開した `assets/mech/idle.png`, `walk.png`, `jump.png` をプロジェクトの同じ場所へコピー
3. Godotを開きF5で実行

| 状態 | 画像 | フレーム |
|---|---|---|
| 待機 | idle.png | 9 |
| 歩行 | walk.png | 8 |
| ジャンプ | jump.png | 8 |

左右移動は A/D または左右矢印、ジャンプは Space。
画像が未配置の場合は仮メカが表示されます。
ジャンプ用の画像は歩行フレームを再編集した暫定素材です。
画像をGitHubへ反映するには `git add assets/mech/*.png && git commit -m "Add mech animation assets" && git push` を実行してください。


## 標準2脚（関節制御・試作版）
`scripts/standard_biped.gd` で2ボーンIKの歩行を実装しています。手前側・奥側は180度位相差で動き、膝が目標足首位置に合わせて曲がります。`stride`（歩幅）、`step_height`（足上げ）、`cycles_per_second`（歩行速度）を変更可能です。`assets/mech/modular/upper_body.png` があれば既存の上半身画像を使い、なければ簡易図形を表示します。脚は現段階では図形による仮表示で、関節ごとの装甲画像は今後追加します。実機での表示調整は未実施です。
